# Glass Effect Pro — Optical Glass UI Showcase & Studio

Figma Optical Glass 10종 시그니처 아이콘과 2020 오리지널 8종 스쿼클 앱 아이콘의 **2026 광학 글래스 리마스터**를 한 곳에서 탐색·편집·내보내기할 수 있는 인터랙티브 웹 스튜디오입니다.

🌐 **Live Demo (GitHub Pages):** https://eric1013-pro.github.io/glass-effect-pro/

## ✨ 주요 기능

- **6종 Figma Optical Glass 히어로 쇼케이스**: 실시간 3D 틸트, 커서 반응형 스페큘러 광택, 실제 클립 굴절(Clipped Refraction) 및 베벨 필터 적용
- **2020 → 2026 Heritage 8종 리마스터 갤러리**: 클라우드·마켓·오디오·노트·네트워크·칩셋·기어·메시지 8종을 `2026 Glass Remaster` / `Hover 비교` / `2020 Original` 3가지 모드 및 `3D 레이어 분해` 뷰로 비교
- **5종 시그니처 아이콘 4단계 분해 (`Slides 2–7`)**: 평면 프레임(180×200) → 그라디언트 → 광학 글래스 → 최종 하이라이트 구조를 3D Z-스택으로 확인
- **18종 통합 실시간 광학 스튜디오**:
  - 360° 물리 광원 다이얼 (`315°` 기본 입사광 → 반대 방향 섀도우 & 직교 프리즘 색분산 연동)
  - Frost(블러) · Refraction(굴절 스케일) · Chromatic Dispersion · Opacity · Rim Edge · Ambient Glow · Micro-Grain 실시간 조절
  - 5종 재질 프리셋(`Figma Glass`, `Apple Liquid`, `Prism`, `Crystal`, `Frosted Matte`) 및 7종 2-톤 컬러 리믹스 스와치
  - **CSS / Tailwind / Design Tokens(JSON)** 복사 및 **512px SVG / 1024px 투명 PNG** 즉시 저장
- **실전 광학 글래스 UI 위젯 & 공간 독**: 스튜디오 설정과 실시간 동기화되는 Spatial Audio 플레이어, 스마트 앰비언트 허브, macOS/visionOS 근접 확대 Spatial Glass Dock (`My 2020→2026` / `Figma Glass` 팩 전환)
- **Slide 8 Shadow Lab**: `#E8EAE9` Drop Shadow & Inner Shadow 타일, Elevation 프리셋(`Slide 8 Exact`, `Soft Pillow`, `Deep Float`), 실시간 Violet Halo 강도 조절 및 CSS 복사
